# z53/CoreDNS loopback comparison (#1) — 2026-09-08

Production source: 9a7c2c48c80f584c9f7950cea568dfbedcd5869c
Harness source: 6cd62a7
Safe: unmodified deployed Nix package, ReleaseSafe / baseline CPU.
Fast: same Nix derivation with only -Doptimize=ReleaseSafe replaced by -Doptimize=ReleaseFast.

The workload uses one A record with TTL 3600 and address 192.0.2.1.
The cache also contains one readiness name, outside the timed workload.
Both resolvers retain query formatting and writes to /dev/null.
CoreDNS uses GOMAXPROCS=1 and GOGC=100. GODEBUG and GOMEMLIMIT are absent.
No CPU isolation or frequency control applies. The host retains normal workloads.
RSS comes from /proc/PID/status after each trial. These configurations omit hosts and TLS.
The q=1 runs contain gaps between requests and do not establish maximum throughput.
The 32-outstanding runs report observed throughput, not a full saturation search.

## Reproduction

nix develop
nix build .#z53 --out-link /tmp/z53-compare-safe-package
nix build --impure --expr 'let f = builtins.getFlake "git+file:///Users/matt/code/z53"; in f.packages.aarch64-linux.z53.overrideAttrs (old: { zigBuildFlags = map (flag: if flag == "-Doptimize=ReleaseSafe" then "-Doptimize=ReleaseFast" else flag) old.zigBuildFlags; })' --out-link /tmp/z53-compare-fast-package
python3 scripts/compare-coredns.py --safe /tmp/z53-compare-safe-package/bin/z53 --fast /tmp/z53-compare-fast-package/bin/z53 --output /tmp/z53-coredns-new-run
